## 1. 系统总览：集百家之长

本系统参考了 GitHub 上最受欢迎的一批开源量化项目（2026 年 10 月的 Star 数），取其所长、去其繁重，做成一个能在个人电脑上运行的轻量系统。

|---|---|---|---|
| microsoft/qlib | 约 4.9 万 | AI 因子研究、截面选股、TopK 组合 | `multi_factor` 的截面 z-score 因子打分与 TopK 等权持仓 |
| vnpy/vnpy | 约 4.6 万 | 事件驱动、Gateway 网关抽象、风控模块 | 统一 `Account` 接口：同一策略在回测/模拟/实盘间切换；事前风控检查 |
| mementum/backtrader | 约 2.4 万 | 灵活的事件驱动回测、参数寻优 | `on_bar` 事件循环、网格寻优 |
| quantopian/zipline | 约 2.0 万 | `order_target_percent` 等目标仓位 API、杜绝未来函数 | 目标仓位下单 API；`next_open` 成交模型 |
| freqtrade（5.6 万）、hummingbot（2.1 万） | — | 向量化指标 + 事件决策、止损/保护机制、超参优化 | `prepare()` 向量化指标；止损、移动止损、回撤熔断；参数网格 |

```
执行 Account ── 回测/模拟盘: SimBroker（A股/港股/美股规则撮合）
             └ 实盘: LiveAccount + 券商网关（IBKR/富途/老虎/长桥/miniQMT/easytrader/手工）
   ▼
分析 ── 绩效指标、HTML 报告、本地网页看板
```

## 2. 交易机制与通用约定

### 2.1 信号与成交时点（最重要）

| `fill_at` | 含义 | 适用 |
|---|---|---|
| `next_open`（默认） | 第 T 日收盘后用 T 日及以前的数据算信号，**T+1 日开盘价**成交 | 回测、模拟盘、实盘一致，**无未来函数** |
| `close` | 第 T 日收盘价立即成交 | 仅用于和其他平台对比，结果偏乐观 |

实盘中的对应做法：每个交易日收盘后（或次日开盘前）运行一次，生成委托，次日开盘以市价/保护限价执行。

### 2.2 A股规则（自动执行）

| 规则 | 实现 |
|---|---|
| 最小交易单位 | 买入必须是 100 股整数倍；卖出时零股可一次性卖出 |
| T+1 | 当日买入的股份当日不可卖（`today_bought` 冻结） |
| 涨跌停 | 主板 ±10%，创业板(300/301)/科创板(688) ±20%，北交所 ±30%，ST ±5%；开盘即涨停**买不进**、跌停**卖不出** |
| 停牌 | 当日无行情或成交量为 0 → 委托撤销 |
| 成交量约束 | 单笔委托最多吃掉当根 K 线成交量的 25%（`max_volume_ratio`） |
| 费用 | 佣金万 2.5（最低 5 元）+ 过户费十万分之一（双向）+ 印花税 0.05%（仅卖出，2023-08-28 起） |
| 滑点 | 默认 0.05%，对你不利的方向 |

### 2.3 港股、美股规则

| | 港股 HK | 美股 US |
|---|---|---|
| 交易制度 | T+0，无涨跌停 | T+0，无涨跌停 |
| 每手股数 | **因股票而异**，在配置 `[rules.HK] lot_sizes` 里逐只设置（默认 100） | 1 股 |
| 费用（默认近似富途） | 佣金 0.03%（最低 3）+ 平台费 15/笔 + 印花税 0.1%（**双向**）+ 交易所/证监会/结算费约 0.0105% | 每股约 0.0099 美元（最低 1.98）+ 卖出 SEC 费 |
| 币种 | HKD | USD |

**汇率**：账户以 `base_currency` 记账，跨币种持仓按 `[account] fx_rates` 中的固定汇率折算（回测近似，不模拟汇率波动）。建议 A股、港股、美股**分账户分配置**运行，与真实券商账户一一对应。

### 2.4 数据约定

- 价格使用**前复权**数据；分红送转已体现在价格中。
- 代码格式统一为 `代码.市场`：`600519.SH`、`000001.SZ`、`00700.HK`、`AAPL.US`；配置里写 `600519`、`700`、`AAPL` 也会自动识别。
- **幸存者偏差**：用“今天的成分股”回测过去，会高估收益。正式研究请使用历史成分股或更宽的股票池。

## 3. 风控模块

风控对所有策略生效，在 `[risk]` 段配置。**卖出（减仓）永远放行**，所有限制只作用于买入。

| 参数 | 默认 | 说明 | 建议值 |
|---|---|---|---|
| `max_position_weight` | 1.0 | 单票最大仓位占比；超出会**自动缩量**而不是拒单 | 个股 0.1–0.25；ETF 可 1.0 |
| `max_order_value` | 0（关） | 单笔委托金额上限（基础货币） | 实盘初期建议设置，防止参数写错 |
| `max_daily_orders` | 0（关） | 单日买入委托数上限 | 20 |
| `blacklist` | [] | 禁止买入的代码（ST、问题股） | — |
| `stop_loss` | 0（关） | 固定止损：价格 ≤ 成本 ×(1−x) 卖出 | 个股 0.08–0.15 |
| `trailing_stop` | 0（关） | 移动止损：价格 ≤ 持仓期最高收盘 ×(1−x) 卖出 | 0.10–0.20 |
| `take_profit` | 0（关） | 止盈：价格 ≥ 成本 ×(1+x) 卖出 | 趋势策略不建议开 |
| `max_holding_days` | 0（关） | 时间止损：持有满 N 个交易日卖出 | 反转策略 5–20 |
| `max_drawdown_halt` | 0（关） | 账户回撤达到 x 时熔断，`halt_cooldown_days` 天内禁止开仓 | 0.15–0.25 |
| `halt_liquidate` | false | 熔断时是否同时清仓 | 保守账户 true |

止损类信号在收盘后检查，**次日开盘卖出**；若次日开盘跌停则卖不出（真实世界同样如此），会在之后继续尝试。

辅助函数 `position_size_by_atr()`：海龟式风险仓位——触发 ATR 止损时，单笔亏损不超过总资产的 `risk_per_trade`。

### 4.1 动量轮动 `momentum_rotation`

**思想**：强者恒强。在一篮子相关性较低的品种中，定期买入近期走势最强的 1–3 个；所有品种都走弱时转入避险资产（国债 ETF）或空仓。这是 A股小资金最常见、也最容易理解的中低频策略（俗称“ETF 轮动”）。

**信号**

1. 每个调仓日（`rebalance`：`W` 每周第一个交易日 / `M` 每月第一个交易日）计算每个品种的动量得分：
   - `score = "r2_slope"`（默认）：对最近 `lookback` 日的对数价格做线性回归，得分 = 年化斜率 × R²。既要涨得快，又要涨得稳，能过滤“一根大阳线”造成的假动量。
   - `score = "return"`：简单区间收益率 `close / close[lookback] - 1`，可配合 `skip` 跳过最近几天（规避短期反转）。
2. 只保留 `score > abs_threshold` 的品种（**绝对动量**过滤），按得分取前 `top_k` 名。
3. 等权持有入选品种；名额不足的部分分配给 `safe_asset`（若配置），否则持有现金。
4. 权重变化小于 5% 的品种不调仓，节省成本。

**参数**

| 参数 | 默认 | 说明 | 建议寻优 |
|---|---|---|---|
| `lookback` | 25 | 动量窗口（交易日） | 20 / 25 / 60 |
| `top_k` | 1 | 持有品种数 | 1–3 |
| `score` | r2_slope | 得分方式 | r2_slope / return |
| `rebalance` | W | 调仓频率 | W / M |
| `abs_threshold` | 0.0 | 绝对动量门槛 | 0 |
| `safe_asset` | "" | 避险品种，如 `511010`（国债ETF） | — |
| `skip` | 0 | 计算收益时跳过最近 N 日（仅 return 模式） | 0 / 5 |

**推荐品种池**（A股 ETF，彼此相关性低）：沪深300ETF 510300、中证500ETF 510500、创业板ETF 159915、纳指ETF 513100、黄金ETF 518880；避险：国债ETF 511010。港美股可用 SPY/QQQ/TLT/GLD/EFA 等。

**优势**：规则简单、换手低、只交易 ETF（无个股暴雷、ETF 免印花税）、资金容量大。

**风险与失效场景**：市场来回反复、没有主线时会反复“追高杀跌”；`top_k=1` 时单品种集中，回撤可能较大；品种池选择本身存在“后视镜偏差”。

**配置示例**：`examples/cn_etf_rotation.toml`

### 4.2 量价多因子选股 `multi_factor`

**思想**：借鉴 qlib 的截面选股框架。每月对股票池中所有股票计算若干因子，做截面标准化后加权求和，买入综合得分最高的 `top_k` 只，等权持有。

**因子定义**（全部只用量价数据，任何数据源都能算）

| 因子 | 公式 | 方向 | 逻辑 |
|---|---|---|---|
| 中期动量 `momentum` | `close[t-mom_skip] / close[t-mom_n] - 1` | 越大越好 | 中期趋势延续；跳过最近一个月以规避短期反转 |
| 低波动 `lowvol` | `-(mom_n 日收益率标准差 × √252)` | 波动越低越好 | 低波动异象：低风险股票长期风险调整收益更高 |
| 短期反转 `reversal` | `-(close / close[rev_n] - 1)` | 近期跌得多越好 | A股散户占比高，短期过度反应后均值回归 |
| 流动性 `liquidity` | `-ln(1 + liq_n 日平均成交额)` | 成交额越小越好 | 非流动性溢价（小盘/冷门）；默认权重 0，谨慎开启 |

**打分**：每个因子在当日截面做 z-score（±3σ 截尾），乘以权重 `w_*` 后相加。

**大盘择时（可选）**：设置 `market_symbol`（如 510300）和 `market_ma`（如 120），当该指数 ETF 收盘价低于其均线时清仓空仓。

| 参数 | 默认 | 说明 |
|---|---|---|
| `top_k` | 10 | 持股数量 |
| `rebalance` | M | 调仓频率 |
| `w_momentum` / `w_lowvol` / `w_reversal` / `w_liquidity` | 1 / 1 / 0.5 / 0 | 因子权重，0 表示不用 |
| `mom_n` / `mom_skip` | 120 / 20 | 动量窗口与跳过天数 |
| `vol_n` / `rev_n` / `liq_n` | 60 / 5 / 20 | 各因子窗口 |
| `market_ma` / `market_symbol` | 0 / "" | 大盘择时 |

**优势**：分散持股、逻辑有学术支持、可持续扩展（加入基本面因子只需在 `prepare` 中多算一列）。

**风险**：因子会阶段性失效（如 2017 年小盘因子大幅回撤）；个股有暴雷、停牌、退市风险；股票池过小时截面排名不稳定（建议 ≥ 30 只）；月度调仓的交易成本需要计入。

**配置示例**：`examples/cn_multi_factor.toml`

### 4.3 风险平价 `risk_parity`

**思想**：让每类资产对组合的风险贡献大致相等，而不是资金相等。股票波动大就少配，债券波动小就多配，组合整体回撤显著小于纯股票。

**规则**：每月计算各资产 `vol_n` 日年化波动率 σᵢ，权重 wᵢ ∝ 1/σᵢ，归一化后单资产不超过 `max_weight`（超出部分按比例分给其他资产）。可选 `target_vol`：按（忽略相关性的保守）组合波动缩放总仓位，不足部分持有现金。

| 参数 | 默认 | 说明 |
|---|---|---|
| `vol_n` | 60 | 波动率窗口 |
| `rebalance` | M | 调仓频率 |
| `max_weight` | 0.6 | 单资产上限 |
| `target_vol` | 0（关） | 目标年化波动，如 0.08 |

**推荐资产**：A股可用 沪深300ETF、中证500ETF、国债ETF 511010、十年国债ETF 511260、黄金ETF 518880、纳指ETF 513100；美股可用 SPY、QQQ、TLT、IEF、GLD、DBC、EFA。

**优势**：回撤低、几乎不需要择时、适合作为整个账户的“底仓”。

**风险**：股债同时下跌（如 2022 年美股美债双杀）时失效；简化版只用波动率倒数，没有考虑相关性；收益通常低于纯股票。

**配置示例**：`examples/us_risk_parity_ibkr.toml`

### 4.4 双均线趋势 `dual_ma`

**思想**：最经典的趋势跟踪。短期均线上穿长期均线（金叉）说明趋势转强，买入；下穿（死叉）卖出。

**信号**

- 买入：`MA(fast)` 今日上穿 `MA(slow)`（昨日 ≤，今日 >）；若 `trend_filter > 0`，还要求收盘价 > `MA(trend_filter)`。
- 卖出：`MA(fast) < MA(slow)`。
- 仓位：资金分成 `max_positions` 份（0 = 股票池数量），每个信号占一份；信号多于空位时，按 20 日动量从高到低优先。

| 参数 | 默认 | 建议寻优 |
|---|---|---|
| `fast` | 10 | 5 / 10 / 20 |
| `slow` | 30 | 30 / 60 / 120 |
| `trend_filter` | 0 | 0 / 120 / 250 |
| `max_positions` | 0 | 视股票池大小 |

**优势**：能抓住大趋势，规则透明。**风险**：震荡市频繁假信号、来回止损（胜率通常 30–40%，靠少数大赚覆盖多次小亏）；信号滞后，顶部回吐利润较多。建议配合 `trailing_stop`。

**配置示例**：`examples/hk_trend_futu.toml`

### 4.5 MACD 趋势 `macd_trend`

**信号**

- 买入：MACD 柱（`2×(DIF−DEA)`）由负转正，且收盘价 > `MA(filter_ma)`（只在长期上升趋势中做多）。
- 卖出：MACD 柱 < 0，或收盘价跌破 `MA(filter_ma)`。

| 参数 | 默认 | 建议寻优 |
|---|---|---|
| `fast` / `slow` / `signal` | 12 / 26 / 9 | 8–12 / 26–34 / 9 |
| `filter_ma` | 120 | 60 / 120 / 250 |
| `max_positions` | 0 | — |

**优势**：比双均线更早响应趋势变化，长期均线过滤减少熊市中的逆势交易。**风险**：参数对品种敏感；震荡市信号多。

---

### 4.6 海龟突破 `turtle`

**思想**：经典海龟交易法则的简化版——价格突破过去 N 日最高价入场，跌破过去 M 日最低价离场，用 ATR（平均真实波幅）决定仓位和止损。

**信号与仓位**

- 买入：收盘价 > 过去 `entry_n` 日最高价（不含当日）。
- 卖出：收盘价 < 过去 `exit_n` 日最低价，或跌破入场时设定的止损价 `入场价 − stop_atr × ATR`。
- 仓位：`股数 = 总资产 × risk_per_trade / (stop_atr × ATR)`，即触发止损时亏损约为总资产的 `risk_per_trade`；同时不超过 `max_weight`。

| 参数 | 默认 | 说明 |
|---|---|---|
| `entry_n` / `exit_n` | 20 / 10 | 入场 / 离场通道（经典系统二为 55 / 20） |
| `atr_n` | 20 | ATR 窗口 |
| `risk_per_trade` | 0.01 | 单笔风险占总资产比例 |
| `stop_atr` | 2.0 | 止损距离（ATR 倍数） |
| `max_weight` | 0.25 | 单品种最大仓位 |

**优势**：风险预算清晰，波动大的品种自动少买。**风险**：假突破多、胜率低；A股 T+1 和涨跌停会放大跳空风险。

---

### 4.7 RSI 超卖反转 `rsi_reversion`

**思想**：“顺大势、逆小势”——只在长期上升趋势中，买入短期超跌的股票，等反弹后卖出。

**信号**

- 买入：`RSI(rsi_n) < buy_below` 且收盘价 > `MA(trend_ma)`。
- 卖出：`RSI > sell_above`，或持有满 `max_hold` 个交易日（时间止损）。
- 多个信号时优先买 RSI 最低的。

| 参数 | 默认 | 建议寻优 |
|---|---|---|
| `rsi_n` | 6 | 2 / 6 / 14 |
| `buy_below` | 20 | 10 / 20 / 30 |
| `sell_above` | 60 | 50 / 60 / 70 |
| `trend_ma` | 120 | 120 / 200 |
| `max_hold` | 10 | 5–20 |

**优势**：胜率较高（通常 > 55%），持仓周期短。**风险**：单笔盈利小，交易成本敏感；趋势反转时“越跌越买”会带来大亏，务必开启 `stop_loss`。A股 T+1 下次日才能卖出。

---

### 4.8 布林带回归 `bollinger_reversion`

**信号**

- 买入：昨日收盘价在布林下轨之下，今日收盘重新站上下轨（确认企稳，而不是“接飞刀”）；可选 `trend_ma` 过滤。
- 卖出：收盘价回到中轨（`MA(n)`）。

| 参数 | 默认 | 建议寻优 |
|---|---|---|
| `n` | 20 | 20 / 30 |
| `k` | 2.0 | 1.5 / 2.0 / 2.5 |
| `trend_ma` | 0 | 0 / 120 |

**适用**：宽基 ETF 的震荡市。**风险**：单边下跌趋势中会连续失败。

---

### 4.9 网格交易 `grid`

**思想**：以 `center_n` 日均线为中枢，每偏离一个网格（`step`，如 3%），就调整一档仓位：价格越低仓位越高，越高仓位越低，在震荡中低买高卖。

**规则**：网格档位 `level = round(ln(价格/中枢) / ln(1+step))`，限制在 ±`levels`；目标仓位 `= base_weight − level × base_weight / levels`，截断到 [0, `max_weight`]。档位变化时才调仓。

| 参数 | 默认 | 说明 |
|---|---|---|
| `symbol` | 股票池第一个 | 交易品种 |
| `center_n` | 120 | 中枢均线（动态中枢，避免价格单边远离后失效） |
| `step` | 0.03 | 网格间距 |
| `levels` | 5 | 单边网格数 |
| `base_weight` / `max_weight` | 0.5 / 0.95 | 中枢处仓位 / 最大仓位 |

**优势**：震荡市收益稳定，心理压力小。**风险**：单边下跌会满仓被套；单边上涨会过早卖光、跑输持有。只适合长期不会归零的宽基 ETF。

---

### 4.10 买入持有 `buy_hold`

在第一个交易日等权买入股票池全部品种并一直持有。用作对照组：**任何策略如果在样本外长期跑不赢买入持有（扣费后、经风险调整后），就没有必要使用。**

## 7. 编写自己的策略

新建一个 Python 文件（例如 `my_strategy.py`），继承 `Strategy` 并注册：

```python
import pandas as pd
from quantum_analyze import indicators as ta
from quantum_analyze.strategies.base import Strategy, register

@register("my_breakout")
class MyBreakout(Strategy):
    title = "我的突破策略"
    default_params = {"n": 20, "weight": 0.2}
    param_grid = {"n": [10, 20, 40]}

    def prepare(self, data):
        # 只能用 rolling / shift 等“向后看”的计算
        for sym, df in data.items():
            self.ind[sym] = pd.DataFrame({
                "high_n": df["high"].rolling(self.n).max().shift(1),
                "ma": ta.sma(df["close"], self.n),
            })

    def on_bar(self, ctx):
        for sym in ctx.universe:
            if not ctx.is_trading(sym):
                continue
            hi, ma = self.value(ctx, sym, "high_n"), self.value(ctx, sym, "ma")
            if hi is None:
                continue
            px = ctx.price(sym)
            if px > hi and sym not in ctx.positions:
                ctx.order_target_percent(sym, self.weight)
            elif px < ma and sym in ctx.positions:
                ctx.order_target_shares(sym, 0)
```

在使用前 `import my_strategy`（或放进 `quantum_analyze/strategies/builtin.py`），配置里写 `name = "my_breakout"`。

**Context 常用 API**

| 方法 | 说明 |
|---|---|
| `ctx.dt` | 当前 K 线时间 |
| `ctx.universe` | 股票池 |
| `ctx.price(sym)` / `ctx.bar(sym)` | 最新收盘价 / 当根 K 线（停牌返回 None） |
| `ctx.history(sym, "close", n)` | 截至当前的最近 n 根数据 |
| `ctx.is_trading(sym)` | 当日是否有成交 |
| `ctx.is_period_start("W"/"M"/"Q")` | 是否为周/月/季的第一个交易日 |
| `ctx.order(sym, qty)` | 按股数买（正）卖（负） |
| `ctx.order_target_shares / value / percent` | 调整到目标股数 / 金额 / 仓位比例 |
| `ctx.rebalance({sym: w})` | 一次性调到目标权重组合，未列出的持仓卖出 |
| `ctx.positions` / `ctx.cash` / `ctx.total_value` | 持仓 / 现金 / 总资产 |
| `ctx.state` | 需要跨日保存的变量（模拟盘/实盘会持久化） |
| `ctx.log(msg)` | 记录日志 |

**避免未来函数的三条规则**：`prepare` 里只用 `rolling`/`ewm`/`shift(正数)`；不要用 `shift(-1)`、全样本 `mean()`/`std()` 标准化；不要在 `on_bar` 里直接读 `ctx.data[sym]` 的整表。

- **实盘**：收盘后数据更新完毕、或次日开盘前运行 `qa live -c 配置.toml`。默认 `dry_run = true` 只打印委托。确认无误后用 `qa live --send`（需输入 YES 确认）或在配置中设 `dry_run = false`。建议设置 `limit_offset`（如 0.01）把市价单转为保护性限价单。
- **自动调度**：`qa schedule -c 配置.toml --mode paper --at 15:30` 常驻运行；或者使用 Windows 任务计划程序 / macOS launchd / Linux cron 每天定时运行一次 `qa paper`。

### 8.5 实盘安全建议

1. 永远先用券商的模拟账户（IBKR 模拟端口、富途 SIMULATE）跑通全流程。
2. 首次实盘设置 `[risk] max_order_value`，防止参数错误导致超大委托。
3. 不要把密码、Token 写进配置文件或提交到 Git，使用环境变量。
4. 每天核对一次券商端实际持仓与看板是否一致。
5. 出现异常（数据缺失、委托被拒）时，系统会在日志里记录，请及时人工处理。

## 9. 绩效指标释义

| 指标 | 含义 | 参考 |
|---|---|---|
| 年化收益 | 复合年化增长率（CAGR） | 与基准比较 |
| 年化波动 | 日收益标准差 × √252 | — |
| 夏普比率 | (年化收益 − 无风险利率 2%) / 年化波动 | > 1 较好，> 2 需警惕过拟合 |
| 索提诺比率 | 只用下行波动的夏普 | 越高越好 |
| 最大回撤 | 净值从最高点到最低点的最大跌幅 | 决定你能否坚持 |
| 最长回撤期 | 净值低于前高的最长交易日数 | — |
| 卡玛比率 | 年化收益 / 最大回撤 | > 0.5 可接受 |
| 交易胜率 | 盈利的平仓次数 / 总平仓次数 | 趋势策略 30–45%，反转策略 55%+ |
| 盈亏比(总) | 总盈利 / 总亏损 | > 1.5 较好 |
| 年换手 | 年成交额 / 平均资产 / 2 | 换手越高，费用越敏感 |
| Alpha / Beta | 相对基准的超额收益 / 市场敞口 | — |
| 信息比率 | 年化超额 / 跟踪误差 | > 0.5 较好 |

## 10. 常见问题

**Q：为什么回测和别的平台结果不一样？**
主要差异来自成交价（本系统默认次日开盘价）、费用（最低 5 元、印花税）、涨跌停不可成交、复权方式和数据源。将 `fill_at` 设为 `close` 可与“收盘价成交”的平台对比。

**Q：模拟盘第一天为什么没有成交？**
第一天只生成委托，下一个交易日开盘才成交，与实盘一致。

**Q：可以用分钟线吗？**
可以，`[data] frequency = "5m"` 等（取决于数据源支持）。T+1 按自然日解锁；`is_period_start` 仍按交易日判断。中低频策略推荐日线。

**Q：港股每手股数在哪里查？**
在券商 App 的个股页面查看，填入 `[rules.HK] lot_sizes`。

**Q：多个策略如何同时运行？**
每个策略一份配置文件、一个状态文件（`trading.state_file` 不同）。实盘时注意多个策略共用一个券商账户会互相影响持仓，建议用子账户或在一个策略内组合。
