# 新手教程：从零开始跑第一个回测

这份教程假设你的电脑上什么都没装。照着做完，你会在自己电脑上用**真实行情**跑出第一份回测报告。全程免费，不需要开券商账户。

大约需要 30 分钟，其中大部分时间在等下载。

> 教程里所有 `命令` 都在“终端”里输入：Windows 用 **PowerShell**（开始菜单搜索 PowerShell），Mac 用 **终端 Terminal**（启动台 → 其他 → 终端）。每输入一行按一次回车。

---

## 第 1 步：安装 Python

本软件需要 **Python 3.10 或更新版本**（推荐 3.12）。

**Windows**

1. 打开 https://www.python.org/downloads/ ，下载最新的 Python 3.12 或 3.13 安装包。
2. 运行安装包，**一定要勾选最下面的 “Add python.exe to PATH”**，再点 “Install Now”。
3. 装完后**重新打开** PowerShell，输入：
   ```powershell
   python --version
   ```
   显示 `Python 3.12.x` 之类的版本号就成功了。

**Mac**

1. 同样从 https://www.python.org/downloads/ 下载 macOS 安装包并安装。
2. 打开终端输入：
   ```bash
   python3 --version
   ```

> Mac 上后面所有的 `python` 都换成 `python3`。

---

## 第 2 步：下载软件代码

**方法 A（推荐）：用 Git**

1. 安装 Git：Windows 从 https://git-scm.com/download/win 下载安装，一路“下一步”即可；Mac 在终端输入 `git --version`，按提示安装。
2. 选一个放代码的位置（例如桌面），然后下载：
   ```bash
   cd Desktop
   git clone https://github.com/ZeyuLiR/quantum-analyze.git
   cd quantum-analyze
   git checkout claude/quant-trading-system-1k5d8c
   ```
   如果仓库是私有的，会弹出 GitHub 登录窗口，用你的 GitHub 账号登录即可。

   > 最后一行切换到软件所在的分支。等 PR 合并到 `main` 以后就不需要这一步了。

**方法 B：直接下载压缩包**

打开 https://github.com/ZeyuLiR/quantum-analyze/tree/claude/quant-trading-system-1k5d8c ，点绿色的 **Code → Download ZIP**，解压后在终端里 `cd` 进入解压出来的文件夹。

> 建议放在**没有中文和空格的路径**下，例如 `C:\quant\quantum-analyze`，能避免很多奇怪的问题。

---

## 第 3 步：创建虚拟环境并安装

虚拟环境是一个独立的 Python 小房间，装的东西不会影响电脑上其他程序。

在 `quantum-analyze` 文件夹里依次输入：

**Windows（PowerShell）**
```powershell
python -m venv .venv
.venv\Scripts\Activate.ps1
```
如果提示“无法加载，因为在此系统上禁止运行脚本”，先执行下面这行再重试：
```powershell
Set-ExecutionPolicy -Scope CurrentUser RemoteSigned
```

> 如果你用的是“命令提示符”（cmd，提示符形如 `C:\CODE\quantum-analyze>`），`.ps1` 不会生效，请改用：
> ```bat
> .venv\Scripts\activate.bat
> ```

**Mac**
```bash
python3 -m venv .venv
source .venv/bin/activate
```

激活成功后，命令行最前面会出现 `(.venv)`。**以后每次打开新终端，都要先 `cd` 到这个文件夹再执行一次激活命令。**

然后安装软件和免费数据源：

```bash
python -m pip install -U pip setuptools wheel
pip install -e ".[cn]"
pip install yfinance
```

- `.[cn]` 会装上 A股免费数据源 AkShare 和 BaoStock。
- `yfinance` 是美股/港股的免费数据源。
- 在国内下载慢，可以在每条 `pip install` 后面加上清华镜像：`-i https://pypi.tuna.tsinghua.edu.cn/simple`

> 一定要先执行第一行升级 pip 和 setuptools，否则安装 AkShare 时可能报 `Failed building wheel for jsonpath`。

检查是否装好：

```bash
qa strategies
```

能看到 `momentum_rotation 动量轮动`、`multi_factor 量价多因子选股` 等 10 个策略的列表，就说明安装成功了。

## 第 4 步：离线跑通一次（不需要联网）

先用软件自带的合成数据把流程跑通：

```bash
qa backtest -c examples/quickstart.toml
```

终端会滚动输出一些日志，最后打印一张绩效表，并告诉你报告文件的完整路径，例如：

```
报告: C:\quant\quantum-analyze\examples\reports\multi_factor\report.html
```

用浏览器打开这个文件（Windows 可以直接输入 `start examples\reports\multi_factor\report.html`，Mac 输入 `open examples/reports/multi_factor/report.html`）。

> 合成数据是随机生成的，收益**没有任何参考意义**，这一步只是确认软件能正常运行。

## 第 5 步：用真实 A股数据回测

我们用最适合新手的 **A股 ETF 动量轮动** 策略：每周在 沪深300、中证500、创业板、纳指、黄金 这 5 只 ETF 中，买入近期走势最强的那一只；全部走弱时转入国债 ETF。

**5.1 先下载数据（可选，用来确认网络正常）**

```bash
qa fetch -c examples/cn_etf_rotation.toml
```

成功时每只 ETF 会显示一行，例如：

```
510300.SH      2xxx 根K线  2015-01-05 ~ 2026-10-19
```

数据会缓存在 `examples/data_cache/`，下次运行只补下载最新几天。

**5.2 运行回测**

```bash
qa backtest -c examples/cn_etf_rotation.toml
```

报告在 `examples/reports/momentum_rotation/report.html`。

> 这个配置默认从 2016 年开始回测，初始资金 20 万。数据源顺序是 AkShare → BaoStock → Tushare，第一个失败会自动换下一个。注意：BaoStock 不提供 ETF 数据，ETF 主要靠 AkShare。

---

## 第 6 步：看懂回测报告

报告页面从上到下依次是：

1. **指标卡片**：最重要的看这几个
   | 指标 | 看什么 |
   |---|---|
   | 年化收益 | 每年平均赚多少，和下面的“基准年化”比 |
   | 最大回撤 | 历史上从最高点最多亏了多少。问问自己：亏这么多我还拿得住吗？ |
   | 夏普比率 | 每承担一份风险换来多少收益，> 1 算不错；> 2 要警惕是不是过拟合 |
   | 卡玛比率 | 年化收益 ÷ 最大回撤，> 0.5 可以接受 |
   | 年化超额 | 比基准（沪深300指数）每年多赚多少 |
   | 总交易费用 / 年换手 | 交易是否太频繁，费用吃掉了多少收益 |
2. **净值曲线**：蓝线是策略，灰线是基准（都从 1 开始）。
3. **回撤图**：红色越深越长，说明那段时间越难熬。
4. **月度收益表**：每个月赚亏多少，看看是不是只靠少数几个月赚钱。
5. **风控事件**：止损、熔断触发的记录。
6. **成交记录**：每一笔买卖的日期、价格、数量、手续费和盈亏。

同一个文件夹里还有 `equity.csv`（每日资产）、`trades.csv`（成交）、`orders.csv`（委托），可以用 Excel 打开。

## 第 7 步：动手改一改

**7.1 临时换参数（不改文件）**

```bash
qa backtest -c examples/cn_etf_rotation.toml --params "lookback=60;top_k=2"
```

意思是：动量窗口改成 60 天、同时持有 2 只。每个策略有哪些参数可以改，见 `qa strategies` 或 [策略说明书](策略说明书.md) 第 4 章。

**7.2 换回测区间**

```bash
qa backtest -c examples/cn_etf_rotation.toml --start 2020-01-01 --end 2024-12-31
```

**7.3 改配置文件**

用记事本、VS Code 等编辑器打开 `examples/cn_etf_rotation.toml`（建议先复制一份，例如 `my_etf.toml`）：

- `[account] initial_cash`：初始资金
- `[universe] symbols`：股票池，A股直接写 6 位代码（如 `"600519"`），港股写 5 位（如 `"00700"`），美股写代码（如 `"AAPL"`）
- `[strategy] name`：换策略，例如改成 `"buy_hold"` 就是“买入持有”，可以用来做对照
- `[strategy.params]`：策略参数
- `[risk]`：止损、仓位上限等风控（见说明书第 3 章）

改完保存，再运行 `qa backtest -c examples/my_etf.toml`。

**7.4 和“买入持有”比一比**

任何策略如果长期跑不赢简单的买入持有，就没必要用。把 `name` 改成 `"buy_hold"` 跑一次，对比两份报告。

## 第 9 步：检验是不是“过拟合”

回测结果好看，不代表实盘能赚钱。挑参数时最容易犯的错误，就是把参数调到刚好适合历史数据。

```bash
qa optimize    -c examples/cn_etf_rotation.toml
qa walkforward -c examples/cn_etf_rotation.toml
```

- `optimize`：把一组参数全试一遍，按夏普排序。**不要直接选第一名**，要看相邻参数是不是也都不错（参数高原）。
- `walkforward`：用前 3 年选参数、在后 1 年检验，然后滚动往前。最后的“样本外拼接表现”才更接近真实水平。

## 常见问题

**`qa` 不是内部或外部命令 / command not found**
虚拟环境没激活。先 `cd` 到 quantum-analyze 文件夹，执行第 3 步的激活命令；或者用 `python -m quantum_analyze` 代替 `qa`。

**`所有数据源均失败`**
- 提示“未安装 xxx”：执行 `pip install -e ".[cn]"`。
- 提示网络错误：AkShare 的数据来自东方财富等国内网站，挂了海外代理/VPN 时可能访问失败，关掉试试；yfinance 相反，在国内可能需要代理。
- AkShare 接口偶尔会因为网站改版失效，先升级：`pip install -U akshare`。
- 加 `-v` 可以看到完整报错，例如 `qa -v backtest -c ...`。

**想强制重新下载数据**
加 `--refresh`，或者删除 `examples/data_cache` 文件夹。

**提示缺少 Tushare token**
这只是说明 Tushare 没配置，前面的数据源成功时可以忽略。想用 Tushare 时在 https://tushare.pro 注册，把 token 设为环境变量 `TUSHARE_TOKEN`。

**报告里收益和别的平台不一样**
本软件默认“今天收盘出信号，明天开盘成交”，并且计算了最低 5 元佣金、印花税、涨跌停买不进等真实规则，通常比只用收盘价成交的平台保守。详见说明书第 10 章。
