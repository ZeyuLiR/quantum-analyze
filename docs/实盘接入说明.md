# 实盘接入说明

各数据源和券商接口按官方 SDK 文档编写，但开发环境无法安装券商客户端、也无法访问行情网站，**没有在真实账户上运行过**。请按本文顺序在你自己的电脑上逐个验证，先用模拟账户。

## 1. 推荐的接入顺序

1. `qa backtest -c examples/quickstart.toml`：确认软件本身能运行。
2. 接数据：`qa fetch -c examples/cn_etf_rotation.toml`（A股，AkShare/BaoStock 免费），`qa fetch -c examples/us_risk_parity_ibkr.toml`（美股，yfinance 免费）。
3. 内置模拟盘：`qa paper -c ...`，连续运行几个交易日。
4. 券商模拟账户：IBKR 模拟端口 / 富途 `paper = true`，`qa live -c ...`（默认 dry-run，只打印委托）。
5. 确认 dry-run 委托正确后，在模拟账户上 `qa live --send`。
6. 最后才换成实盘端口/账户，并设置 `[risk] max_order_value`。

## 2. 券商网关

| 网关 | 安装 | 需要运行 | 配置 `[trading.gateway_options]` |
|---|---|---|---|
| `ibkr` | `pip install ib_async`（或 `ib_insync`） | TWS 或 IB Gateway，开启 API 端口 | `host`, `port`（7497 TWS 模拟 / 7496 TWS 实盘 / 4002 Gateway 模拟 / 4001 Gateway 实盘）, `client_id`, `account` |
| `futu` | `pip install futu-api` | FutuOpenD | `host`, `port=11111`, `paper=true`, `markets=["HK","US"]`, 实盘密码放环境变量 `FUTU_TRADE_PASSWORD` |
| `tiger` | `pip install tigeropen` | — | `props_path`（tiger_openapi_config.properties 目录）, `account` |
| `longbridge` | `pip install longport` | — | 环境变量 `LONGPORT_APP_KEY / APP_SECRET / ACCESS_TOKEN` |
| `qmt` | 券商 QMT 客户端自带 `xtquant` | miniQMT（极简模式登录） | `path`（userdata_mini 目录）, `account_id` |
| `easytrader` | `pip install easytrader` | 同花顺/通用版交易客户端（仅 Windows） | `client`, `exe_path` |
| `ptrade` | — | — | 导出委托 CSV，由 Ptrade 内的模板策略读取下单（见 `PTRADE_STRATEGY_TEMPLATE`） |
| `manual` | — | — | `orders_path`、`state_path`：委托写入 CSV，人工下单 |
| `sim` | — | — | 内置撮合 |

### 需要你在本机核对的细节

- **IBKR**：港股市价单在 SEHK 是否被接受；沪深港通 A股只能限价单（网关会拒绝市价单，请设置 `limit_offset`）；IBKR 不返回可卖数量，沪深港通 A股的 T+1 需要自己注意。
- **富途**：新版 OpenD 是否允许通过 API `unlock_trade`（否则在 OpenD 界面解锁）；市价单 `price=0` 是否被接受。
- **老虎**：资产与持仓字段名（`cash_available_for_trade`、`salable_qty` 等）。
- **长桥**：港股是否接受 `OrderType.MO`；`submitted_quantity` 的类型。
- **miniQMT**：科创板市价单是否必须带保护价；`avg_price`/`open_price` 字段名。
- **easytrader**：不同客户端返回的中文列名不同，已做多候选名兼容。

## 3. 数据源

| 名称 | 安装 | 需要 | 已知注意事项 |
|---|---|---|---|
| `akshare` | `pip install akshare` | — | 指数成交量单位按“手”换算；美股带点的代码（BRK.B）格式需核对 |
| `baostock` | `pip install baostock` | — | 不含北交所；停牌日无数据 |
| `tushare` | `pip install tushare` | `TUSHARE_TOKEN` | 日线成交量“手”、成交额“千元”已换算 |
| `qmt` | 随 QMT | miniQMT 运行中 | 成交量单位按“手”换算，时间戳按毫秒解析 |
| `futu` | `pip install futu-api` | FutuOpenD | 历史 K 线有额度限制，`start` 不要设得太早 |
| `yfinance` | `pip install yfinance` | — | 港股代码自动转为 `0700.HK` 格式 |
| `ibkr` | `pip install ib_async` | TWS/Gateway + 行情订阅 | 日线 `ADJUSTED_LAST` 只能取到最新 |
| `alphavantage` | — | `ALPHAVANTAGE_API_KEY` | 免费 Key 可能只能取非复权数据，会打印警告 |

建议 `[data] validate = true` 跑一次，看两个数据源的收盘价是否一致，再决定主数据源。

## 4. 安全

- 密码、Token 一律放环境变量，不要写进配置文件；`.gitignore` 已忽略 `.env` 和 `*.secret.toml`。
- `qa live` 默认 dry-run；`--send` 需要输入 `YES` 确认；无人值守运行请在配置中显式设置 `dry_run = false`。
- 同一根 K 线不会重复下单（状态文件记录 `last_bar`）。
